# TaskFlow - Premium SaaS Task Management

TaskFlow is a modern, production-ready full-stack SaaS application built for teams. It features a polished, dark-theme interface inspired by Linear and Vercel, providing a high-performance environment for project tracking, task management, and team collaboration.

## 🌟 Features
- **Role-Based Access Control (RBAC):** Distinct dashboards and permissions for Admins (global stats, management) and Members (personal productivity).
- **Interactive Kanban Board:** Fluid drag-and-drop task management.
- **Dynamic Projects Dashboard:** Track project progress, upcoming deadlines, and team activity timelines.
- **Premium UI/UX:** Built with Tailwind CSS featuring glassmorphism, responsive data charts, and skeleton loaders.

---

## 🏗 Architecture Overview
TaskFlow utilizes a decoupled client-server architecture:
- **Frontend (Client):** A Vite-powered React Single Page Application (SPA).
- **Backend (Server):** An Express REST API with JWT-based stateless authentication.
- **Database Layer:** Prisma ORM interfacing with a PostgreSQL database, secured by Row-Level Security logic at the controller layer.

### Tech Stack
- **Frontend:** React 18, Vite, React Router v6, Tailwind CSS, Recharts, Lucide-React, hello-pangea/dnd.
- **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), bcrypt.js.
- **Database:** PostgreSQL via Prisma ORM.

## 💻 Local Development Setup

### 1. Clone & Install Dependencies
```bash
git clone <your-repo-url>
cd TaskFlow
```

### 2. Backend Setup
```bash
cd server
npm install
```
Create a `.env` file inside `/server`:
```env
PORT=5000
DATABASE_URL="postgresql://user:password@localhost:5432/taskflow?schema=public"
JWT_SECRET="your_secure_development_secret"
NODE_ENV=development
FRONTEND_URL="http://localhost:5173"
```
Initialize your database and start the server:
```bash
npx prisma db push
npm run dev
```

### 3. Frontend Setup
Open a new terminal window:
```bash
cd client
npm install
```
Create a `.env` file inside `/client`:
```env
VITE_API_URL="http://localhost:5000/api"
```
Start the frontend:
```bash
npm run dev
```

## 🚄 Production Deployment to Railway

This project is fully hardened for a zero-downtime deployment on [Railway](https://railway.app).

### 1. Provision the Database
- Create a **New Project** on Railway.
- Select **Provision PostgreSQL**.
- Retrieve the generated `DATABASE_URL` from the Variables tab.

### 2. Deploy the Backend
- Add a new **GitHub Repo** service connected to your TaskFlow repository.
- Under **Settings -> Build**, set the **Root Directory** to `/server`.
- Add the following Environment Variables:
  - `DATABASE_URL`: *(Your Railway PostgreSQL Connection String)*
  - `JWT_SECRET`: *(Generate a secure 64-character random string)*
  - `PORT`: `5000`
  - `NODE_ENV`: `production`
  - `FRONTEND_URL`: *(Leave blank for now, you will add your frontend's public URL here later)*

### 3. Deploy the Frontend
- Add a second **GitHub Repo** service for the same repository.
- Under **Settings -> Build**, set the **Root Directory** to `/client`.
- Add the following Environment Variable:
  - `VITE_API_URL`: *(The public domain generated by your Railway Backend service, e.g., `https://taskflow-api.up.railway.app/api`)*

### 4. Finalizing the Connection
- Once the Frontend is deployed, copy its public domain URL.
- Go back to your Backend service variables and set `FRONTEND_URL` to this URL to satisfy the strict CORS policy.

### 5. Seed Production Data (Optional)
To populate your production database with the Alice and Bob demo accounts:
1. Open the Railway dashboard for your **Backend** service.
2. Open the **Command Palette (Ctrl + K)** or the Railway CLI.
3. Run the seed script:
```bash
node prisma/seed.js
```
